# Academic Workflow Automation with n8n — Presentation

Author: Adele Lerman  
Source: Presentation - AI-Automation.pdf

Short summary
-------------
A slide deck describing an "AI-Powered" workflow built with n8n for tracking news sentiment and brand insights. The presentation demonstrates a Google News RSS → sentiment analysis → Google Sheets + automated email reporting flow, and highlights the business value of automating brand reputation monitoring.

What's in this repo
-------------------
- Presentation - AI-Automation.pdf — the complete slide deck (created with Canva; metadata indicates some AI-generated content).

Key topics covered in the slides
-------------------------------
- News Sentiment Tracking Workflow
- Brand reputation monitoring and automated reporting
- Google Sheets integration and email notifications
- How the workflow is triggered (manual Execute Workflow button in n8n)
- Example output and action-oriented insights for brands
- Business value of automation for continuous monitoring
